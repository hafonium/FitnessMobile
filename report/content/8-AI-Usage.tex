\section{AI Usage Statement}

AI tools were used as development assistants for planning, code generation, debugging, documentation, and report drafting. Team members remained responsible for project decisions, source control, testing, and the final submitted work.

For implementation, generated suggestions were reviewed against the existing architecture and edited before inclusion. Repository code, Room entities, Gradle configuration, build output, device logs, and Git history were treated as the source of truth. The team did not assume that generated code was correct because it compiled.

For this report, AI assisted with organizing the required topics and converting repository evidence into clear prose and tables. Claims were checked against the inspected source files and actual verification results. The report explicitly records incomplete work, including the Room schema collision, missing tests on the chatbot branch, lint failure, fixed player timers, and the API-key risk.

The application's own chatbot also uses an AI model. User messages and a rolling context summary are sent to Groq, while message history is stored locally in Room. The current assistant should be treated as general informational support, not medical diagnosis or a substitute for a qualified trainer or healthcare professional.
